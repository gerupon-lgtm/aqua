## 2. 盤面（S-03・S-07）

- 真横から見た断面。画面の上下が高さ
- グラス：透明な縦長のグラス。位置は固定、中の水面だけが上下する
- グラスの側面に等間隔の目盛り。音名は表示しない
- 水の色：少ないグラスは明るく、多いグラスは暗く。水面の線とグラスの輪郭は色とは別にはっきり描く
- グラスの光：水位が目盛りに乗ると光る（淡い金色）
- 水面の揺れ：目盛りからずれているほど大きく揺れる（補助。動きを減らす設定では止める）
- 前回の水面の線：編集中、グラスは空にし、前回の水位を薄い点線で示す。点線の上に「前回」の札（点線と同じ茶色、高さ・文字は「高さ」の札と同じ）を添え、目標の高さと読み違えないようにする（共有資料 U-08、2026-11-03 発案者が枠つきの札を選択）
- 新しいパーツの初出説明（T-08、v0.17.0）：6面（水門）・13面（太さを選べる配管）・19面（噴水盤の高さ）・25面（サイフォンと桶）を初めて開いたとき、前作の鏡の説明と同じ形の窓を画面の中央に出す（見出し・挿絵 intro-*・説明・「やってみる」・×）。どのモードでも出し、チュートリアルのスキップとは別にパーツごとに一度だけ（D-08 の parts）。×・「やってみる」・窓の外・Esc で閉じ、閉じてから700ms待って開始の合図を始める。見直しはメニューの「パーツの説明」。2つの噴水盤はお試し3面が初出で精霊の案内があるため、窓は出さない（v0.17.3で7面の窓を外した）
- グラスの名前：給水塔と同じ青い札で「グラスA」などを口の縁に載せる（解説の呼び名と対応させる）。盤面の上へははみ出させない（狭い画面で盤面が縮むため）。サイフォンが口から入るグラスは、縦の管を隠さないよう管の山の上へ置く（2026-11-03 発案者、v0.16.0）
- 水が届かなかったグラスに「空」の札は出さない。必要量の札の下に隠れていたため、2026-11-03 発案者の判断で廃止（v0.14.16）。空であることはグラスの見た目と噴水盤の赤い札（届いた量0）で伝える
- 管：通り道の高さを本物として描く。交差は上下にずれて越える。合流はグラスでだけ
- サイフォン：未開通・開通・切れたを、形や印でも区別する（色だけに頼らない）。未開通は、山の所に空気（泡）がたまっている様子で示し、上流の水面が山より高くても流れない理由が分かるようにする（要件5.2）
- 出口：白い石の噴水盤。縁に必要量の印。クリアすると、ジングルの鳴り始めと同時に噴水が噴き上がる。100点は噴き上がった後に虹。NGは噴かない。実行後、印の手前で止まるかあふれるかで過不足を見せる
- 空のグラス：給水塔につながっていないグラスは空のまま。【想定】「つながっていない」印を付けるかは試作で決める
- 流れの向き：計算で決まった向きを、水の動きで見せる（前作の向きの矢印は使わない）
- 拡大・移動：前作と同じ（余白のドラッグで移動、二本指・ホイール・＋−で拡大縮小、全体表示）

## 4. 両方の端末・向き

- PC・スマホ・タブレット、縦向き・横向きのすべてで主要な操作を最後まで行える（要件9章）
- 画面全体のスクロールを出さない。長い一覧はページ切替、広い盤面は盤面内の移動・拡大縮小（前作と同じ）
- 狭い幅で、条件・水を流す・停止・結果が隠れないこと
- 盤面の大きさは面によって変えない（2026-11-01 発案者）。条件の欄（面の名前・出題・噴水盤の指定・桶・つないだ本数）は、面の名前の長さや噴水盤の数で折り返しの行数が変わるため、その端末・その画面幅で全部の面の条件の欄を測り、一番高いものに高さをそろえる（書体の読み込み後と画面幅が変わったときに測り直す）
- iPhone（WebKit）の文字の自動拡大は止める（text-size-adjust: 100%）。結果のトーストで一部の文字だけが大きくなり横にはみ出したため（2026-11-01、iPhone XR の Chrome）。トーストの中身は横にはみ出さず、広い表だけが表の枠の中で横に動く
- 文字の折り返し（2026-11-01 発案者）：1行に収まる文は折り返さない（縦の高さを増やさない）。収まらないときだけ、言葉の途中ではなく文節の区切りで折り返す（CSS の word-break: auto-phrase。対応していないブラウザでは通常の折り返し）。かっこ書きと前の数値（例「5/4（約1.25）」）、「届いた 〜」「指定 〜」はひとかたまりにする。ボタンの文字は折り返さず、並びきらないときはボタンごと次の行へ送る。更新の案内は中身の幅で画面の中央に置く

## 6. v0.14.2 の見た目（2026-11-01）

- 噴水盤は白い陶器の枠とガラスの内器。前面と奥側の目盛りは浅く湾曲させ、必要量を淡い金色で示す。届いた量0では水を描かない。
