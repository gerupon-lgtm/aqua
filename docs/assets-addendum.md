# 絵の追加発注書（盤面の部品の残り・画面の部品・ロゴ）

版：v0.1（2026-11-01）。docs/assets.md（発注書 v0.1）の追加分。共通の決まり（世界観・色・禁止事項・保存先・採用と出所の記録）は docs/assets.md の 2章・5章に従う。

## 1. 前提：今の画面はすべて仮

https://aqua.sikumilab.com/ の見た目は、色・形・ボタン・文字の札・アイコン・ロゴまで、すべて試作の仮のもの。配置（どこに何があるか）と大きさは v0.12.0 の骨組みで決まっているので、配置は変えずに、見た目を作る。

この追加分は、動きや大きさがその場で変わるものが多いので、多くは**デザイン表（見本の一枚絵）**で発注する。採用されたデザイン表を元に、Claude が図形（SVG）と画面の書式（CSS）で作る。デザイン表には、見本として文字や数字を入れてよい。

## 1-2. 部品と背景の境界（2026-11-01 決定）

明るい背景の上で、白・透明の部品（グラス・泉・噴水盤・配管・水）が溶け込まないようにする。前作は暗い背景に、部品の周りの淡い陰影と明るい縁取りで分けていた。本作は明るい背景なので、その逆にする。

- 部品の縁は濃い青（ 前後）で縁取る（バインディング）。透明な部品も、縁取りで形が分かるように描く
- 部品の周りだけに、淡い青の陰影を置く。背景全体を暗くしない
- 絵の質感（透明な素材、映り込み）は絵の作り手が描く。アプリは、採用された絵に合わせて縁取りの太さと色をそろえる（v0.13.1 の縁取りは暫定）

## 3. 盤面の部品

### 3-1. 配管（sheet-pipe）

配管は、面ごとに違う道筋（地面の下を通る、L字に曲がる、グラスの底につながる）をアプリが線で描く。太さは3段（太1・中2・細3。画面上の太さはおよそ 10・6.5・4、盤面の座標で）。絵を道筋に沿わせることはできないので、見た目の決まりをデザイン表で示す。

デザイン表に入れるもの：

- 素材と断面：外のふち・内側・中の水の重ね方（いまは「ふちの線＋中身の色」の2層）。白い陶器、透明なガラス管、白い石の水路など、2〜3案
- 3つの太さを並べた見本
- 状態：候補（まだつないでいない。いまは灰色の点線）／つないだ（水なし）／水が流れている（流れの向きが分かる白い点の列が動く）／太さを選べる候補
- 曲がり角（L字）・グラスの底との継ぎ目・2本が近く並ぶところ（重なっても行き先が分かること。T-13 の課題「配管が重なって行き先が見えない」）
- 太さの札（docs/assets.md の ui-badges）を配管の上に置いたときの見え方

### 3-2. サイフォン（sheet-siphon）

壁を越える配管。グラスの中から上に伸び、壁の上を越えて隣へ下りる。

デザイン表に入れるもの：

- 呼び水の前：山の部分に空気がたまっている（いまは白い泡3つ）
- 桶で呼び水をした後：管が水で満ちている
- 流れているとき・切れたとき（空気が入って流れが止まる。後続の面で使う）
- 桶（docs/assets.md の part-bucket）で呼び水をする様子の見本（任意）

### 3-3. 水・目盛り・グラスの光（sheet-water）

水位はアプリが動かすので、描き方の決まりをデザイン表で示す。

- グラスと泉の中の水の色（深さで少し濃くなる）と、水面のゆらぎの線
- 目盛り（グラスの左の短い横線）と、前回の水面の線（いまは金の点線）
- 目盛りに乗ったときのグラスの光（淡い金。いまは太い半透明の線を重ねている）
- 目盛りからずれたとき（いまは水面が揺れる）
- 空のグラス（いまは「空」の文字）
- 噴水盤の中の水（指定の線まで・多いとき・少ないとき）

### 3-4. 壁と水門の追加

- 壁（part-wall）：docs/assets.md の繰り返しの石に加えて、壁の上に載せる笠石を1つ
- 水門（part-gate）：開いた状態と閉じた状態の2枚（いまは白と黒の四角）

## 4. 画面の部品（UI）

### 4-1. 画面の見本（sheet-ui-play・sheet-ui-title）

今の画面の配置をそのまま下敷きにして、見た目を作った画面の見本を描く。縦のスマホ（1170×2532、iPhone の画面の比率）。

- タイトル画面：ロゴ（とシリーズの表記「SIKUMI NOTES 02」）、一言、ボタン（チュートリアル／連続プレイ／選択プレイ・自由作成／パーツの説明・遊び方と概要／プレイ画面へ・更新）、版数と「© SIKUMI LAB」
- プレイ画面（編集中）：上の段（ロゴ・記録・音・メニュー）、面の切り替え（‹ 名前 ∨ ›）、条件カード、盤面、案内の行（水の精霊）、下のボタン（配管クリア・水を流す）
- プレイ画面（結果）：結果のトースト（100点・クリア・NG、点数、出口ごとの結果、解説、ボタン）

前作のプレイ画面（スマホ縦：docs/reference/prism-v0.100.0-q3-layout.png、PC：docs/reference/prism-v0.79.0-q6-pc-layout.webp）と同じシリーズに見えること。前作が夜（濃紺と金）、本作は昼（白と青、淡い金）。

PC（横長の画面、1920×1080 の見本を1枚追加）は、前作の PC 版の配置に合わせる（参考：docs/reference/prism-v0.79.0-q6-pc-layout.webp、部品の多い面 docs/reference/prism-v0.79.0-q42-pc-board.webp）：

- 上の段：左にロゴとタイトルの一言、右に「記録・音・更新・☰」
- 左に大きな盤面（枠つき。背景の絵が盤面いっぱいに見える）。盤面の下に操作の行（前作は配線クリア・操作補助・秒数・拡大縮小。本作は配管クリアなど）。盤面の左下に凡例（前作は「結線済み／結べる道」。本作は「つないだ配管／つなげる配管」）
- 右の列：面のまとまりの名前、「‹ 面の名前 ∨ ›」、条件カード（「この課題の条件」と ⓘ、条件の一文）、資源の欄（前作は配線の本数の 上限・使用・残り を大きな数字で。本作は配管の本数・桶の残り・連続プレイのNGの残り）、状況の一行、下に大きな主ボタン（水を流す）と小さなボタン（停止など）
- いまの本作は、PC でもスマホと同じ縦1列を中央に置いているだけ（仮）。PC の配置は、この見本の採用後に Claude が組む

### 4-2. 画面の部品のデザイン表（sheet-ui-parts）

見本の中の部品を、状態ごとに並べる。

| 部品 | 状態 |
|---|---|
| ボタン（大・ふつう・小・丸い選択肢） | ふつう・押せない・選んでいる・目立たせる（金の光の枠：案内で押してほしいとき） |
| 条件カード | 「クリア条件」・条件の一文・資源の行（桶・配管の本数・NGの残り） |
| 面の切り替え | ‹ › と、名前・所属・∨ |
| トースト（選択肢・予想の問い・結果） | 結果は 100点・クリア・NG の3つ、「最高点」「最少」の印 |
| 下から出るシート | メニュー・記録・面の一覧・レベルの選択 |
| 案内の行 | 水の精霊の小さな姿と文 |
| 更新の案内 | 「新しい版があります」「更新する」 |

### 4-3. アイコン（sheet-icons）

いまは文字や記号で代用しているものを、線のアイコンにする（前作の方式に合わせ、種類の違うアイコンを混ぜない）。

- 音オン・音オフ、メニュー（☰）、記録、前へ（‹）・次へ（›）・一覧を開く（∨）、閉じる（×）
- 小さく使う印：最高点の印（★100点・●クリア）、桶、配管、NG

## 5. ロゴ

ロゴは、前作と同じく書体（Montserrat）の2段の形で作ると決まっている（構想たたき台 4章）。書体の文字としてアプリに組むので、画像ではなくデザイン表で発注し、採用案を Claude が文字と図形で作る。

### 5-1. 作品のロゴ（logo-aqua）

- 「AQUA / NOTES」の2段。前作の「PRISM / NOTES」と同じ書体・比率・字間。色は白と青
- 水らしさを足す飾り（しずく・波紋など）を入れる案と、入れない案
- 明るい背景の上・濃い背景の上の両方の見本

### 5-2. シリーズのロゴ（logo-series）

- シリーズ名は **SIKUMI NOTES**（2026-11-01 決定）。作品のロゴと同じ2段の組み方で「SIKUMI / NOTES」
- 作品のロゴの上に小さく添える形「SIKUMI NOTES 01」（プリズム・ノーツ）・「SIKUMI NOTES 02」（アクア・ノーツ）の見本
- 夜（前作）と昼（本作）のどちらの画面にも合う色。単色版も
- 副題の案「しくみを、音で確かめる。」を添えた見本（採否は未確認）
- 作り手の SIKUMI LAB とのつながりが分かること
