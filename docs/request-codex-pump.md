# Codex への依頼：手押しポンプの絵（31〜36面、T-14）

2026-11-04 Claude 作成。発案者の依頼「T-14を進めて下さい」により、31〜36面「高さを直して呼び水」の計算・面・操作を v0.18.0 で実装しました。盤面のポンプは、文字の札（「ポンプ 入口n」の点線の札）で仮に表示しています。絵・組み込み・配置は Codex の担当です（docs/assets.md の分担）。禁止事項は発案者が決めます。

## 仕組み（絵を決めるための前提）

- ポンプは、面ごとに**グラスA**に置かれています。A→B の壁を越えるサイフォン（`ABs`）の呼び水に使います。
- 汲めるのは、そのサイフォンを除いた今のつなぎ方で落ち着いたとき、グラスAの水位が**サイフォンの入口**の高さ以上のときだけです（要件5.2）。編集中はグラスが空なので、押したときに計算で判断します（2026-11-04 発案者が選択）。
- 汲めないときは、窓に「グラスAの水位が…で、入口の高さ…に届きません」と出ます。何度でも使え、桶は減りません。
- 入口の高さは面ごとに2か3です。盤面で**入口の高さが読めること**が遊びの要です。今の仮の札は、入口の位置（サイフォンの左の脚の下端、グラスAの中）に置いています。

## お願いしたいもの

| 名前 | 用途 | 置き場所・大きさ（docs/assets.md の計画） | 優先度 |
|---|---|---|---|
| part-pump | 盤面の手押しポンプ。仮の札「ポンプ 入口n」を置き換える | 盤面、256×384、RGBA | 1 |
| intro-pump | 31面を初めて開いたときの説明の挿絵（ほかの intro-* と同じ形） | 960×360、文字なし | 2 |
| bg-pump | 31〜36面の背景「井戸と手押しポンプのある丘の村」 | 1536×1536、RGB | 3 |

組み込むときの注意（今の実装で決まっていること）：

- 入口の高さ（「入口2」「入口3」）が盤面で読めるようにしてください。数字の札は、ほかのバッジと同じ高さ・書体にそろえてください。
- ポンプで呼び水をしたサイフォンは、桶のときと同じ「水で満ちた管」の描き方になっています。ポンプで呼び水をしたかどうかを絵で区別するかは、Codex と発案者に任せます。
- `src/ui/board.js` の「手押しポンプ」の箇所（グラスの描画の中）が、仮の札を出している所です。
- 31面の説明の窓（`src/content/tutorial.js` の `PART_INTROS`）は、intro-pump が届いてから T31 を足します。文の案：「グラスAのポンプで、壁を越える管に呼び水ができます。」「Aの水位が入口の高さ以上のときだけ汲めます。桶は減りません。」

## 確認に使える面

選択プレイの31〜36面です。31面は入門、32面は「水位を上げてから汲む」、35面は「太さで水位を保つ」で、どれも出題8つずつがあります。
