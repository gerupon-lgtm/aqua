# v0.26.2 パーツの説明・遊び方の再構成

2026-11-05。発案者が、プリズム・ノーツの粒度で説明を再構成し、利用できる自由作成も案内するよう依頼。v0.26.1の配置修整を保持して、説明の文章と読み進め方を変更した。公開状態は末尾に記録する。

## 基準と構成

前作0.101.0のsrc/ui/help.jsと、partsExplanation・aboutGame・helpCardを参照。役割を短く知る一覧から詳しい説明へ進む構成とし、長い一続きの文章を、役割・操作・流れの条件などの小見出しへ分ける。前作の光の操作や採点を本作へ移すものではない。

- パーツ11項目：給水塔、グラス、配管と丸札、噴水盤、高さの違う出口、選べる太さ、サイフォンと桶、手押しポンプ、排水口、二つの給水塔、水門。
- 遊び方12項目：課題、接続、実行、結果の4手順。流れの決まり、点数、モード、音・表示・更新。自由作成の配置と接続、持ち上げた管、見本と和音のお題、記録と回路の扱い。
- 各一覧は4項目ずつ、前へ・次へで3ページ。詳細から元のページと項目へ戻る。閉じる・戻るボタンを下に残し、キーボードの操作先も説明内へ保つ。
- スマホは1列、PCは2列の一覧。本文は読みやすい幅に抑える。長い詳細はシート内で縦に読み進める。プレイ画面の配置や高さは変更しない。

本文はsrc/ui/help-content.js、一覧と詳細の組み立てはinfo-copy.js。既存の挿絵5種類を維持する。初出説明で使うpartPictureの呼び出し方も保つ。

## 現行機能との照合

旧説明の「自由作成：準備中」を解消し、画面にある操作を案内する。給水塔1つ・グラス最大3つ、接続・太さ・噴水盤・山のつまみ・桶・水門・基本と和音のお題を、free.js・free-samples.js・app.jsと照合した。手押しポンプと排水口は課題側の部品として説明する。

連続プレイは現在のCONTINUOUS_STAGESどおり1〜30面。選択プレイは全54面。NG上限はフリーなし・ビギナー20・ノーマル10・エキスパート5。出題数は面ごとに異なる。桶・排水口の面で先に比べる観点もplay.jsに合わせる。

噴水盤の必要量は毎秒の量で、蓄積する水位ではない。管の数字は直径そのものではない。グラスの光は音の目印で、課題の正解とは区別する。水の出口がなく給水塔と同じ高さまで満ちる説明は、給水塔が一つの場合と明示する。

自由作成の回路は現在state.freeにだけ保持され、ページを再読み込みすると引き継がれない。和音のお題の達成の印と課題の成績は別にブラウザへ保存する。この違いも説明し、画面にない回路保存・入出力を実装済みとして案内しない。

計算・出題・採点・音・保存の実装は変更していない。src/logicとsrc/contentの差分なし。今回のapp.jsの変更は版番号と説明画面の入口・一覧・詳細・フォーカス。版とキャッシュは0.26.2へ更新する。
