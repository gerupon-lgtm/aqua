# v0.14.11 配管の交差の切れを修正

発案者から、配管の交差が途切れて見える画像を受領。8面で同じ症状を再現した。交差の曲線を後から描く前に、背景色の四角で下の縦管まで広く消していたことが原因。

## 変更

- pipePathの実際に描く線へまたぎの曲線を含める。直線へ曲線を後付けする方式をやめ、前後を連続した1本の管とする。端の曲がりへ逆戻りしない幅で曲線を作る。
- 下の管を消す背景の四角を廃止。細い影と曲がった管そのものだけを前へ描く。前へ描く範囲はclipPathで限定し、管の色と流れの点はdrawPipeを共用する。未接続が交差だけ実線になったり、接続や水の色がそこで変わったりしない。
- 接続点・地中の段・グラス・器と札の位置、数学上の経路pts・計算・出題・採点・保存・音・噴水と虹の待機は維持。layout.stageは表示用の交差探索への参照で、保存には入れない。既存のdata-pipe-bridgeによる直接の押下も保持する。

## 点検

- 再現テストは修正前に「T8: 交差の下の縦管が消える」で失敗。修正後に成功。全168テスト・構文42ファイル・出題の再生成比較が合格。v0.14.11のビルドと通信なし資材57件が成功。
- 実際の描画画像の同じ点は、修正前RGB(190,157,106)の土色、修正後RGB(242,250,229)の管の色。before.jpg / after.jpg / continuity-pixels.jsonで対応する。
- 交差のある8・9・12・21・22・24面を5状態ずつ点検。計30表示・40か所で、不要な背景の四角0、本体と交差の描く線・色・流れの点の位置が一致（states.json）。
- 本体の8面で、SBのまたぐ部分を直接押した後、下の縦管ACを押し、SBとACの2本だけを別々に接続できた。
