# v0.14.9 高さの数字と下部ボタン

発案者が、グラスの目盛りに数字がなく読みにくい点と、プレイ下部のボタンを結果表示へそろえることを指摘。共有の「2026-11-02-height-flow-display.md」U-01に共通の数字付きの物差しと給水塔の目盛り、U-02に給水塔の高さ表示が記載されていたが、反映が漏れていた。

## 変更

- U-01：盤面左端の既存の余白へ、0〜給水塔の高さまでの共通の物差し。地面が0、1目盛りが高さ1。数値・グラス・給水塔の刻みはすべてlayout.yOfで同じ高さへ置く。白い面と青い数字で空の背景から分ける。各グラスへ同じ数字を重ねず、左の1本で比べる。
- 給水塔の青い水面にも、グラスと同じ間隔で白い刻みを追加。U-02：給水塔の札の下に「高さ6」などを表示する。出題で変化した現在の値を使う。札の2段化は従来の表示範囲内に収める。
- 物差しに重なる出口の太さの丸札だけを移動し、左端の数字を覆わない場所を探す。配管の道筋、出口と器の高さ、グラスと水位の座標、画面の枠や表示倍率は変えない。
- 練習のグラスの説明とパーツの説明に、共通の数字と高さ1の読み方を反映。計算・出題・採点・保存・音・結果待機は変えない。
- 下部の操作は結果カードと同じ3等分・6px間隔、内側の左右の余白と文字の大きさへ統一。結果／やり直し／次へを左・中・右。編集は配管クリアを中、水を流すを右、実行の停止は中、案内の次へは右。使わない列は空ける。PCも共通の列へそろえ、同じ面の状態間で盤面を縮めない。

プレイ画面のスクロールなし、結果・解説だけの内部スクロールを維持。高さ・流量の共有資料を全て実装したという意味ではない。U-03の出口の口の基準、U-04の器との重なり、U-06の毎秒、U-07の高さと量の区別、U-08の前回の印は別途残る。U-05の管の数字はv0.14.7、U-09の出口の数字で割る説明も同版で反映済み。
