# v0.14.10 出口高さと毎秒の量

計算上の出口高さと絵の口がずれ、必要量・届いた量が器にためる量にも見える状態だった。発案者から正しく表現するよう依頼を受け、共有資料「2026-11-02-height-flow-display.md」U-03・U-06・U-07を表示へ反映した。

## 変更

- 上向きの吹き出し口と実管の終点をlayout.yOf(outlet.height)へそろえる。グラスの同じ高さから8px下へ回り、口へ戻る短い管。途中の高さは計算には使わない。出口のサイズの丸札はその実管から直線で引き出す。
- 「出口高さ0」も含めて高さの札を置く。必要量の札は「必要量2/秒」、条件は「毎秒 … 届ける」、予想・結果・解説・記録は「毎秒」の語で量を示す。高さと流量を区別し、数字・分数・単位は途中で折らない。
- 噴水盤の可変の水位と必要量の水位目印をやめる。陶器の枠とガラス窓を維持し、正の量が届いた時だけ、口から出て下へ抜ける流れを描く。量0は水なし。この流れの高さや粒の数で数値を示さない。成功の噴水は同じ口から始め、100点の虹と結果の待機は保持する。
- 説明の挿絵4枚も水位ゲージを除去し、管の口から流れ出る表現へ同期。高さの挿絵では差を測る下端と実際の口をそろえる。scripts/prepare-diagrams.jsが正本。
- 器の幅62、接続元の右26、グラスの左12が底まで見える範囲、通常の地中配管、盤面の外枠・倍率・下部の3列を保持する。計算・採点・198出題・保存形式・音を変えない。

共有資料U-04の低水位を隠さない条件は既存の範囲を維持して点検。U-08の前回水位の印は残る。資料全体や、自由作成・初出説明の機能接続まで完了したという意味ではない。
