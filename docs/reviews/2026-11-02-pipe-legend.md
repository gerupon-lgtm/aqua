# v0.14.7 管の札と凡例

発案者は、管を表す数値と凡例、チュートリアルでの説明を希望し、札は「太さと数字の2段表記」を選択した。画面の構成を大きく変えず、太・中・細と計算に使う数字を結び付ける。

## 変更

- 通常管と出口管の丸い札を「太／1」「中／2」「細／3」の2段に統一。設定の選択肢にも同じ数字を添える。直径28の札は端からはみ出さず、器の札や他の管の札を避ける。下端では札だけを上へ寄せ、配管そのものは動かさない。通常管の札は下段の数字を押しても選べる。
- 盤面の下に小さな凡例を常設。「同じ高さの差なら、数字が小さいほど多く流れる」という条件を併記する。狭い画面では見出しだけを省き、対応と意味を残す。
- スマホでは盤面の外枠の中に約40pxの凡例欄を設けるため、内部の絵の表示領域はその分短くなる。盤面外枠・条件・案内・操作ボタンの位置と寸法は保つ。PCでは従来の58pxの補助操作欄を使い、配管クリアと接続の凡例も残す。
- 練習の札の説明中は、管の札と下の凡例を青と白の枠で示す。凡例の明るさは最初の1.2秒だけ変化し、枠はその手順中だけ残る。動きを控える端末設定では静止した強調。次の手順・別の面・実行・結果では強調しない。
- チュートリアル、パーツ、計算欄と記録の表示を「管の数字」にそろえる。「流れる量＝高さの差÷管の数字」と、直列では数字を足すことを説明。高い出口も、口と水位の差を出口の管の数字で割ると示す。内部のthinnessという項目名、計算式、採点、198出題、保存形式、音と結果待機は変えない。

高さ・流量の別資料にある全提案を実装したものではない。高さの物差し、毎秒の量の表示などは別途検討する。初出説明窓と既読記録の機能担当、実機受け入れT-12は従来どおり。
