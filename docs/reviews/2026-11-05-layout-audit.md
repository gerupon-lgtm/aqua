# v0.26.1 部品と札の配置点検

2026-11-05。Claudeの機能実装後のv0.26.0（fb9c9f73c6892f03b12534ff8aaa61f08565028c）を基準に、発案者の依頼で表示だけを修整した。公開状態は末尾へ追記する。

## 原因と変更

以前の配置検査は、古いグラス幅と初期の部品だけを主に避けていた。後から増えたポンプ・排水口・水門、前回の水位の札、別のグラスを覆う器が検査に含まれていなかった。点検用の満点配置もポンプと排水口の記号を読み取れず、現行の実行結果と一致していなかった。

- 練習・1面などの出口管の太さ札を、空いている右側へ置く。グラスの絵の縁まで含めて避ける。複数の出口では左右の空きを選ぶ。
- 通常管の札は、水門・ポンプ・排水口・名前・つまみと隣の段の札を一緒に避ける。置き場所の少ない管から決める。配管の接続点と高さは動かさない。
- 出口の引き出し線が通常管の丸札をかすめる10・12面は、横向きの線も使って回避する。
- ポンプの札は二行で壁とグラスの間へ置き、入口の高さへ線を伸ばす。排水口の札は高さ・必要量の札と低い水位を避け、実際の高さ0に残した印へ結ぶ。
- 水門の開閉で札を動かさず、最下段の水門が盤外へ切れない高さへ収める。「前回」の札も最前面へ出し、必要量などを避ける。
- 54面はグラスAと右の給水塔、自由作成は左右のグラスの表示上の横間隔だけを調整。器と別のグラスの重なりを解消する。自由作成の空き枠も同じ位置を使う。高い器・持ち上げた管の名前札とつまみも対象に含める。

計算、分数、出題内容、内容版、採点、音、演出の時間、保存形式、入力を処理するコードは変更していない。src/logicとsrc/contentの差分はない。app.jsは画面の版番号だけを変更。画面・package.jsonを0.26.1にそろえ、公開用の版付き資材とworkerの照合値は既存のビルドで生成する。

## 実画面と検査の限界

Chromeで実際の画面を操作し、練習・1面、ポンプ、排水口、54面、自由作成を確認。排水口の移動後の名札から設定を開き、半分への変更が反映されることも確認した。[1面](2026-11-05-layout-audit/mobile-stage1.jpg)、[ポンプ](2026-11-05-layout-audit/mobile-pump.jpg)、[排水口](2026-11-05-layout-audit/mobile-drains.jpg)、[54面・360×740](2026-11-05-layout-audit/mobile-stage54.jpg)、[54面・PC](2026-11-05-layout-audit/pc-stage54.jpg)、[自由作成](2026-11-05-layout-audit/mobile-free.jpg)、[横向き](2026-11-05-layout-audit/landscape-pump.jpg)。360×740・390×844・1280×800・844×390でページのはみ出し0。[寸法の記録](2026-11-05-layout-audit/responsive.json)。

内蔵ブラウザは接続の作り直しでDOM操作が復旧したが、画像取得だけ時間切れになったためChromeを使用した。Chromeでも背景のタブやサイズ変更直後の画像取得が時間切れになる場合があり、画面を操作した後に実際の描画を確認して保存した。ブラウザ操作の成功、数値による全出題の検査、画像を目視した場面を区別する。

スマートフォンの実機の見え方・指での操作・聴感は未確認。自由作成は代表6例であり、利用者が作れる全組み合わせを網羅したという意味ではない。無理に密な自由配置では、描画を止めず最も重なりの少ない札の配置を使う既存方針を保つ。
