# v0.14.5 見た目と文字組みの再点検

v0.14.4を発案者がスマホで確認し、タイトルの絵・透けるボタン・配管の光・結果の判定と分数・台座・開始時の課題表示を指摘した。前版の機械検査は、この見た目の受け入れを済ませた根拠にはならなかった。今回は実装を直し、文字組みを説明・結果・小窓まで共通化して点検する。

## 変更

1. タイトルの線だけのグラスと噴水盤を、採用済み精霊を画風の参照にして生成した透過部品へ交換。精霊は同じ原本から解像度を上げ、彩度・輪郭・影を調整。メニューと無効なボタンも不透明にし、背景の絵で文字が消えないようにした。[原本と制作指示](../../画面案/2026-11-02-title-art/README.md)。
2. 練習の配管に、ぼかした青い光、青と白の光芯、丸札の周りの輝きを重ねる。通常は1.2秒周期で光量が変わり、控えめ設定では強い光のまま止める。練習中も描き直す時計を動かす。管の取り回し・太さ・接続・選び方を変えない。
3. 「ちょうど」「足りない」「多い」を、色と記号と文字のある塗りつぶしたバッジへ変更。緑の✓、茶橙の−／＋で示す。必要量と届いた量は分数を大きく、約の値を小さく別行に表示。7文字以上の分数はラベルと量を1列にする。
4. 高い噴水盤の台座には不透明な白い陶器の面、青い縁、陰影と地面の足を追加。既存の模様は上に残す。器の固定サイズ62、接続するグラス、出口の高さ、左12の低水位が見える範囲を保持。
5. 面の開始は条件カード全体の面と縁を金色にし、最初の120msで明るくして750msまで保ち、1.1秒で終える。控えめ設定では一定の明るさ。必要量の札も同じ合図を使う。再挑戦やメニュー閉じで反復しない。
6. text-layout.jsで分数・約の値・単位・ゲーム内の語をまとめ、案内・予想・答え合わせ・通常ヒント・結果・解説・設定・記録等から使う。既知の静的説明は短い文節で包む。パーツと遊び方はinfo-copy.jsへ移し、点検と本番で同じ内容を使う。一般の日本語の分かち書きが正しいと仮定した実装にはしていない。

計算・採点・30面198出題・チュートリアルの進み方・保存形式・音・虹の後の結果予約は保持。バージョンと読み込み先はv0.14.5へ更新。

## 点検

- 全159テストが成功。表示と時間の追加7件を含む。構文42ファイル、57資材のビルド、出題データの一致検査も成功。
- 変更前の実アプリで4面SAの5/2を再現。大きな数値欄が2行に折れ、かっこが途中で分かれることを確認。修正後は5/2と小さな（約2.50）がそれぞれ一行になり、320・360幅と横向きでもはみ出さない。
- 本番と同じデータ・計算・表示で198出題、1,688状態を3幅で点検。案内と説明も合わせて5,712表示。途中で7文字の長い分数のはみ出しを発見し、修正後の検出は0。[再現ページと記録](../../画面案/2026-11-02-見た目再点検/README.md)。
- 実アプリの全30面を360×800と1280×800で選択。盤面外枠はそれぞれ328×351.0625／849.609375×660で同じ幅の全ての面が一致。画面と文字の横へのはみ出し0、編集の配管クリアは1個。
- 練習を実操作で完走し、目立つ光と丸札、100点の「ちょうど」バッジを確認。414×896の盤面外枠は編集・実行・結果とも382×450.0625。結果の要素待機は最初の一度だけ時間切れだったが、同じ再生の次の画面取得で結果を確認。コンソールエラーはなし。
- パーツ・遊び方・記録・調整を320・360・414幅で開いて点検。予想の分数選択肢、分数結果、844×390の横向きもはみ出さず、条件と案内の領域が重ならない。語の区切りはスクリーンショットでも点検した。
- 配管の光は通常0.453→0.637と変化し、控えめ1.000。条件カードの全体が金色になること、高い器の白い台座と足が見えることを実画面で確認。

PCのブラウザでの検査と、スマホ実機の受け入れは別。Pixel 6a・iPhone XR等での見え方・指操作・聴感はT-12に未確認として残し、対象から外さない。
