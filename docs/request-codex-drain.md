# Codex への依頼：排水口の絵（37〜42面、T-14）

2026-11-04 Claude 作成。37〜42面「音を調える」の計算・面・操作を v0.19.0 で実装しました。盤面の排水口は、文字の札（「排水口 閉／半分／全開」）で仮に表示しています。絵・組み込み・配置は Codex の担当です。禁止事項は発案者が決めます。手押しポンプの依頼（[request-codex-pump.md](request-codex-pump.md)）とあわせてお願いします。

## 仕組み（絵を決めるための前提）

- 排水口は、面ごとにグラスの底に置かれています。グラスの水を地面（高さ0）へ捨てる口で、噴水盤とは別物です。
- 開け具合は**閉・半分・全開**の3段です。半分は中の管、全開は太い管と同じだけ流れます。
- 編集中に札をタップすると窓が開き、段を選べます。実行中・結果表示中は操作できません。自由作成で実行中に回せるようにするのは後続です。
- 開けると、そのグラスの水位が下がり、つながったほかのグラスの水位と音も変わります。37〜42面の遊びの要は「1か所の調整が全体に響く」ことです。
- 今の段が盤面で読めることが必要です。仮の札は、閉が点線の白、開いているときが青です。

組み込むときの注意（今の実装で決まっていること）：

- `src/ui/board.js` の「排水口」の箇所（グラスの描画の中）が、仮の札を出している所です。タップの範囲は `data-drain` の要素です。
- 3つのグラスが並ぶ面（39・41・42面）では、グラスの間が狭くなります。噴水盤や「必要量」の札と重ならないようにしてください。
- 37面の説明の窓（`src/content/tutorial.js` の `PART_INTROS`）は、intro-drain が届いてから T37 を足します。

## 確認に使える面

選択プレイの37〜42面です。37面は入門、39面は「真ん中のグラスの排水口が両側に響く」、41面は「二つの排水口のどちらを開けるか」です。
