# v0.14.9 高さの数字と操作の位置

発案者の指示は、目盛りを数値で読めること、給水塔の高さを読めること、プレイ下部を結果表示のボタン位置へそろえること。共有資料のU-01・U-02も照合した。本番のSVG・CSSで組み込み、盤面を小さくしたりページをスクロールさせたりしない。

## 再現

1. 3・4・5面を開く。左に0からの物差し、給水塔に高さ8・8・6。グラスと給水塔の刻みが物差しと同じ位置になる。
2. 出題を変更する面では、高さの札と物差しも現在の給水塔の値へ変わる。物差しと太さの札が重ならない。
3. 1面でSAとABを接続し流すと75点。結果を閉じ、下部の結果・もう一度・次へが、結果カードの3列と同じ左端・幅になることを確認。
4. 戻って配管を消し、SAだけをつないで流すとNG。結果・配管を見直すの2つを左・中へ置き、右を空ける。
5. index.htmlの「点検する」で、全199問の目盛りの高さ、丸札との重なり、噴水と虹を含む部品の上端を調べる。実操作の検査の代わりではない。
