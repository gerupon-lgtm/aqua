# v0.14.7 管の札と凡例の実装点検

## 指示と採用

発案者の希望は、従来の画面構成を大きく変えず、管の数字の凡例とそこへ目を向ける案内を加えること。候補の選択は「太さと数字の2段表記」。本番のHTML・SVG・CSSで実装し、別の生成画像は使っていない。

- 丸い札：上に太／中／細、下に1／2／3。太1・中2・細3。
- 凡例：盤面の下に対応と「同じ高さの差なら、数字が小さいほど多く流れる」。スマホにも常設。
- 練習：札を説明する手順で凡例と札を青白く囲む。凡例は初めの1.2秒だけ明るさを変える。動きを控える設定では静止。
- 配管の道筋、接続、段、高い出口、固定の器と低水位の見える範囲、計算と出題は保持する。

## 再現

1. 本体を起動し、選択プレイの「画面の見方」を開く。必要量の説明の次へ進むと、下の凡例と札が囲まれる。次へ進むと凡例の強調は消える。
2. 光っている太1の管を選び、水を流す。100点の結果まで盤面外枠が動かないことを確認する。
3. サイズ変更のできる面で丸い札の数字側を押す。設定から細3などへ変更し、上下の表示と実際の計算値がそろうことを確認する。
4. 本フォルダのindex.htmlで「全出題と説明を点検」を押す。結果の文字組み・案内・説明は本番の関数と198出題を使う。補助用ページであり、ゲームの実操作の代わりではない。
