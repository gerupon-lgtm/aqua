# 配管の交差の点検（v0.14.11）

依頼：管がまたぐ場所で、下を通る管が途切れて見える。添付と同じ描画を8面で再現した。

## 原因と修正

以前は背景色の四角で管を消し、その上へ曲線を描いていた。実際に上の管に隠れる範囲より広く、下の縦管まで消していた。また、管の本体は直線のままで曲線を後付けしていた。

pipePathの描く線へ曲線を含め、1本の連続した管とする。背景を塗って消す処理をやめ、またぐ部分の管と細い影だけを前へ描く。全体と交差で共通の描画を使い、未接続・接続・水の色・流れの点も一致させる。接続点・段・計算・配置は変えない。

## 再現と点検

- index.html：8・9・12・21・22・24面。未接続／接続して編集中／流した後／横の管だけ接続／縦の管側を接続を切り替える。本番の描画と計算を使う。
- before.jpg / after.jpg：同じ8面の未接続。probe.jsonの同じ位置が、修正前は土色、修正後は管の色。PythonとPillowでcheck-continuity.pyを実行するとcontinuity-pixels.jsonを再作成できる。元の画像は手元のみ。
- tests/board.test.jsの「交差の曲線より下…」は修正前に失敗、修正後に成功。見えるはずの縦管が背景で消されないことを点検する。
- states.json：6面×5状態＝30表示・40か所。背景を塗る四角は0、管本体と交差の色・描く線・流れの点の位置は一致。
- after-water.jpg / after-two-crossings.jpg：流れる水と、交差が2か所の面。
- local-t8-body-taps.jpg：実アプリでまたぐSBを直接押し、次に下のACを押して2本を別々に接続できた画面。
- public-assets.json / public-app.json：公開資材59件の一致、旧v0.14.10からの更新、公開版の直接の押下と3寸法の点検。
- public-mobile.jpg / public-pc.jpg：公開本体の実画面。画像は手元に保存し、Gitには含めない。
