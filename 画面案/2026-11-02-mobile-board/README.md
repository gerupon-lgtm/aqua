# v0.14.8 スマホの盤面

発案者の条件は「プレイはスクロールなし」「結果・解説はスクロール可」「視認性を重視」。前版の凡例追加で小さくなった盤面を、文字の縮小で対処しない。

## 再現

1. 本体を390×680、360×740などで開く。ブラウザーの上下の枠を除いた表示領域の寸法。
2. 選択プレイで各面へ進む。課題、管の数字、凡例、本文、操作が画面内に入り、ページを動かさず遊べることを確認。
3. 練習の札の下段の数字を押して接続。100点まで流す。同じ面の外枠と表示範囲が変わらないこと、結果・解説の中だけはスクロールできることを確認。
4. 縦から横、PCの寸法へ変える。編集・結果どちらも表示範囲が正しく切り替わる。
5. このフォルダのindex.htmlで「点検する」。本番の全198出題と練習面を計算し、噴水と虹を含む満点の図形が表示上端で切れないか調べる。背景の空とdefs（絵の定義）は分け、移動した部品も画面上の位置で測る。
