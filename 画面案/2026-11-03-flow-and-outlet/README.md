# v0.14.10 出口高さと毎秒の量の実装確認

生成した画面の絵ではなく、本番の描画・計算・文字組みを使う。依頼は「出口の高さと絵の口を一致させる」「必要量と届いた量が毎秒の量であることを正しく表す」。

## 再現

1. 開発サーバーでこのフォルダのindex.htmlを開き「点検する」。全198出題と練習について、実際の口・高さ・物差し・札・噴水の上端を点検する。
2. text-audit.htmlで「全出題と説明を点検」。本番のdeliveryMarkup・textMarkup・guideMessage・説明定数を読み、5,712表示を点検する。
3. アプリ本体の選択プレイ4面でSAだけを接続して流す。必要量毎秒3に対して毎秒5/2。結果を閉じて出口高さ3の口と小さな流れ、グラス下部の見える範囲を確認する。
4. 1面は中2のSBだけで100点。口からの噴水、虹、結果の順に進む。器にたまる水位は描かず、0の時は水を描かない。
