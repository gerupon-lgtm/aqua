## 噴き出し口と高さ

- グラスからの短いU字管と、吹き出し口の座標は変更しない。口は `layout.yOf(outlet.height)`。
- 新しい盤を口の前後・上下へ配置して、口が盤の内側に来るようにした。盤の中央穴をPNGの透過画素から計測（`asset-metrics.json`）。画像上の穴とSVGの口を同じ点へ合わせる。
- 盤の手前側に口の縁を描き、水の根元が盤の外へ伸びて見えないようにした。給水管は盤の裏を通り、下側の横管と引き出しの接点は見せる。
- 量は毎秒の流量。盤に蓄積する水位やゲージは描かない。穴から排水される見え方とする。噴水の高さ・粒数は定性的な演出で、計算結果を物理シミュレーションするものではない。

## 開く場所

- `index.html?stage=T13&state=empty&badge=one&v=16`：寸法を統一し、引き出し線を調整した一行案の全体と拡大。
- `compare.html?stage=T13&state=empty&v=16`：一行・二行の実画面を並べて比較。
- `screen.html`：本番の配置に基づく全体。`stage=T4` で高い盤、`T23` で高さが違う3個の盤。
- `detail.html`：各盤の拡大。空の盤も確認できる。
- `performance.html`：「3つの噴水盤で測る」で通常の動きと描画時間を点検する。これは端末の控えめ設定にかかわらず、動きを明示的に測るページ。
- `audit.html`：全出題の札・実際の口・PNG中央穴の一致を点検する。

本体の aqua ルートをHTTPで配信して開く。既存の隣の画面案フォルダと本体のデータ・画像を参照する。プレイの操作・保存を行うページではない。

## 生成・描画の正本

画像は内蔵 `image_gen` で生成。現在の盤の指示文は [PROMPT-pan-v2.md](PROMPT-pan-v2.md)、原本は`drain-pan-source-v2.png`。旧素材の指示文は [PROMPTS.md](PROMPTS.md)、原本は `drain-pan-source.png` と `soil-source.png`。原本のαを保持し、余白の切り詰め・比率を保った縮小・圧縮で上記の配信用候補を作った。

`prepare-pan-v2.py` が現在の盤の準備、`prepare-material-assets.py`が旧盤と地面の準備の正本。`materials.js` / `materials.css` が部品の描画と色、`annotations.js`が札、`part-geometry.js`が短い接続管の正本。`prepare-parts-preview.mjs` は、現在の本番描画に噴水・虹の候補を適用し、部品の描き方だけを変更した `board-materials.js` を作る。計算・出題・音・記録は本体と共通。取り込み時は素材を `public/graphics/` へ置き、これらの描画処理を本体へ移し、ガイド枠・説明挿絵・版・通信なし資材も同期する。
