# 噴水盤の高さバッジ：比較案（2026-11-03）

依頼：高さの札を給水塔と同じ形・同じような位置へ置き、必要量n/秒をその上に置いた案。もう1案は高さを器の下部へ重ね、上手く収める方法を検討する。現段階は配置の比較用。

## A：給水塔に合わせて上へ

本番の給水塔の高さと同じ描画関数・字体9・高さ14・二重枠を使う。器の上端から−15に「高さ3」、−32に「必要量3/秒」。高さと必要量の上下関係を入れ替え、給水塔の並びとそろえる。

## B：器の左下へ

中央の吹き出し口、右の水の流れ、下の実管を覆わないよう、左下に幅26・高さ26の2段札「高さ／3」。高さの字はAと同じ9、数字は11.5。左側に残したグラス12の範囲には入れない。太さの引き出し線は実管の左の立ち下がりへつなぎ、札の文字を横切らない直線とする。配管の道筋自体は共通。

## 実画面での確認

- index.html：390×680の同じ画面枠を2つ並べる。空／水が流れた状態／噴水と虹を切り替えられる。
- screen.html?variant=a または variant=b：各案の画面。state=waterは4面SAだけの実計算（毎秒5/2）、state=perfectはSA＋BA＋SB（毎秒3・100点）。
- details.html：同じ水が流れた状態を拡大。board-a.svg・board-b.svgはその時のSVGの保存。
- comparison-empty.jpg / comparison-water.jpg / comparison-perfect.jpg：画面全体。
- comparison-detail-water.jpg：同じ盤面の拡大。画像生成ではなく、本番のSVG描画と計算から作ったスクリーンショット。
