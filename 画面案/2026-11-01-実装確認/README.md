# 本番の描画による実装確認（v0.14.3）

画像生成の完成予想図ではなく、src/ui/board.jsと検査済み出題・計算をそのまま使用。通常の開発サーバーでこのindex.htmlを開く。左は選択状態、右は空。下は同じ描画の拡大。管のタップで接続できる。全30面と出題、編集・全接続・100点・未達・低い水位を切り替えられる。低い水位は実在するつなぎ方から計算して選ぶ。音と結果カード全体はアプリ本体で確認する。

## 発案者の指示と反映

- 実際に本番で実現できるものを見せる。画像生成だけの全体モックは根拠にしない。
- 管上の丸い太・中・細を選択。「出口 太」は使わない。
- 白い陶器の枠にガラスの内器。前面の陶器にも、ガラス越しの奥の陶器にも控えめな湾曲した目盛り。必要量は淡い金色。
- 噴水盤を接続元のグラスの前面に重ねる。ただし低い水位を全て隠すのはNG。左12を底まで見せる。器は全30面で幅62の固定サイズで、複雑な伸縮をしない。高い位置にも対応する。
- 太さ表示は器の左上から直線で引き出す。発案者の図の四角は仮の部品で、四角の指定ではない。下の横線は実配管で、折れた引き出し線ではない。
- 短い出口管は太くしすぎず、細めの固定幅でグラスからつながる形。サイズの情報はバッジに任せる。出口の高さは維持する。
- 配管の位置・高さ・つながりはキルヒホッフを水で表すゲームの意味。器の上へ管を立ち上げた案は撤回した。
- 地中は土の層と小石。噴水と虹を明瞭に。結果は中央の点数と金の月桂樹、同じ幅の3操作。
